# Licenses

This policy applies across all repositories in the [Lind-Project](https://github.com/Lind-Project) organization. Contributions are accepted under the [Contributor License Agreement](CONTRIBUTOR_LICENSE_AGREEMENT.md).

## Specifications

All Lind specification content accepts contributions and is provided under the [Community Specification License 1.0 (Community-Spec-1.0)](COMMUNITY_SPECIFICATION_LICENSE.md).

## Software Source Code

Lind source code accepts contributions and is provided under the [Apache License, version 2.0 (Apache-2.0)](https://www.apache.org/licenses/LICENSE-2.0.txt), or any other permissive license approved by the maintainers.

Repositories that are forks of, or vendor, third-party projects (for example glibc, Wasmtime, or the Linux kernel) keep the upstream project's license for that code. Each repository's `LICENSE` file is authoritative for the code it contains.

## Data

All Lind datasets, such as benchmarks and evaluation data, are provided under any of the [Community Data License Agreements](https://cdla.dev/).

## All Other Documentation

All Lind documentation and resources, such as educational materials, accept contributions and are provided under the [Creative Commons Attribution 4.0 International License](https://creativecommons.org/licenses/by/4.0/). 

Documentation that lives inside a source code repository is provided under that
repository's `LICENSE`.
